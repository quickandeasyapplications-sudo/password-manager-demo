## 📖 How to Use

### 1. View Passwords
- Click on **"My Passwords"** tab to see sample passwords
- Click **"Show"** to reveal a password
- Click **"Copy"** to copy password to clipboard (auto-clears in 30 seconds)
- Click **"Delete"** to remove a password

### 2. Add New Password
- Click on **"Add New"** tab
- Fill in the form:
  - Website/Service Name
  - Username/Email
  - Password
  - Category (Work, Personal, Finance, Social Media, Other)
  - Notes (optional)
- Click **"Save Password"** to store it

### 3. Generate Strong Passwords
- Click on **"Password Generator"** tab
- Adjust password length (8-32 characters)
- Select character types:
  - ✅ Uppercase letters (A-Z)
  - ✅ Lowercase letters (a-z)
  - ✅ Numbers (0-9)
  - ✅ Symbols (!@#$%^&*)
- Click **"Generate Password"**
- View strength analysis
- Click **"Copy to Clipboard"** to use it

### 4. View Security Report
- Click on **"Security Report"** tab
- See statistics:
  - Total passwords stored
  - Strong passwords count
  - Weak passwords count
  - Duplicate passwords detected
- Review security features
